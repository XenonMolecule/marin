## Definitively Proven
1. FP8 weights load successfully on TPU (61/61 shards, multiple times)

## Key Technical Insight
Ahmed's multi-host vLLM setup works because Qwen3/Llama models go through
the JAX flax_nnx path with proper mesh-based PP. DeepSeek V2/V3 is explicitly
disabled from this path (_PP_DISABLED_MODELS) and falls back to the vLLM
PyTorch path where PP does not actually distribute layers (each worker loads
the full 1T model). Removing from PP_DISABLED_MODELS triggers JAX path but
hits mesh/device placement issues that need model-specific fixes.
